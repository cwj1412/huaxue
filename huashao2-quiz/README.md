# 花儿与少年 2 性格测试网站

基于 Python Flask 框架开发的《花儿与少年 2》主题 MBTI 风格性格测试网站。

## 🎯 项目特色

- **7 种经典角色**：宁静、许晴、郑爽、毛阿敏、井柏然、杨洋、陈意涵
- **10 道名场面题目**：聚焦机场初遇、房车座位、尴尬九分钟、经费危机等经典场景
- **行为题设计**：通过具体行为选择而非空泛描述来判定角色
- **原话梗融入**：选项融入节目经典台词和行为模式
- **精美 UI 设计**：渐变背景、动画效果、响应式布局
- **社交分享**：支持一键分享测试结果到朋友圈

## 📁 项目结构


## 🚀 快速开始

### 1. 安装依赖


```bash

```

打开浏览器访问：`http://localhost:5000`

## 🔧 自定义扩展

### 添加新题目

在 `app.py` 的 `QUESTIONS` 列表中添加：

```python
{
    "id": 11,
    "scene": "场景名称",
    "question": "问题内容",
    "options": [
        {"text": "选项文本", "char": "角色 ID"},
        # ... 更多选项
    ]
}
```

### 修改角色配置

在 `app.py` 的 `CHARACTERS` 字典中修改对应角色的：
- `name`: 角色名称
- `title`: 角色称号
- `keywords`: 性格关键词
- `description`: 详细描述
- `quote`: 经典台词
- `color`: 代表色（十六进制）

### 部署上线

#### 方案一：Gunicorn + Nginx（推荐）

```bash
pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```

#### 方案二：Docker 部署

创建 `Dockerfile`：
```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install flask gunicorn
COPY . .
EXPOSE 5000
CMD ["gunicorn", "-w", "4", "-b", "0.0.0.0:5000", "app:app"]
```

#### 方案三：云平台部署

- **Vercel**: 需要适配为 Serverless 函数
- **Railway**: 直接连接 GitHub 仓库自动部署
- **Heroku**: 创建 Procfile 后一键部署
